# Jarvis deliverables

This is the single authoritative documentation tree for Jarvis.

- `architecture`: architecture documents and diagrams
- `plans`: phase plans, sprint plans, and schedules
- `decisions`: architecture decision records
- `research`: literature notes and retained source discussions
- `reports`: benchmark, security, quality, and release reports
- `checkpoints`: concise session/resume state
- `manifests`: generated-file hashes and validation metadata

Large benchmark outputs, model files, caches, and private voice recordings do not belong here; they belong under `storage`.
